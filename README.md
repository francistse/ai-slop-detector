# ai-slop-detector

A **standalone** rubric-based human/AI tone scorer — Cantonese + English, works
at any length (including short ragebait where GPTZero-type detectors are
noise). Verdict: `human-likely` / `ambiguous` / `AI-likely`, with an
AI-probability, confidence, and a per-trait breakdown for editing.

**Jev-only.** The decision signal is a *many-shot* Noul: Jev rates the text
against 3 real-human vs 3 AI-draft exemplars. Laya was removed in v1.1 (it
over-fired on short Cantonese — 17/28 human false-positives in the gold test).

> **Honest contract:** this is a **pattern/rubric scorer, not a ground-truth
> detector**. "AI-likely" means *reads machine-written*, never *provably
> generated by a model*. On the 72-case gold set it scores **0 humans falsely
> accused and 0 AI missed**; borderline cases return `ambiguous` instead of
> guessing. Use for read-only review, never to accuse or gate a person.

## Layout (repo = source of truth)

```
ai-slop-detector/
  detect.py            <- the tool (Jev-only)
  calibration.json     <- per-language verdict thresholds (derived from gold set)
  SKILL.md             <- Hermes skill doc
  eval/                <- ALL test materials (gold sets, prompts, harness, reports)
    README.md          <- test-materials index + naivety assessment
    VERIFICATION.md    <- full report with per-case Jev scores
    bench/             <- prompt-variant benchmark + PROMPTS.md (verbatim)
```

The Hermes install at `~/.hermes/skills/creative/ai-slop-detector/` is a set of
**symlinks into this repo**, so there is a single source of truth — the repo. To
install elsewhere, copy `detect.py`, `calibration.json`, and `SKILL.md`.

## Usage

```bash
# canonical project copy
python3 detect.py --text "你的廣東話帖 ..."            # auto-detects language
python3 detect.py --lang en --text "An obvious AI sentence..."
cat post.txt | python3 detect.py --json
```

Reads `OPENROUTER_API_KEY` from the environment or `~/.hermes/.env` at runtime
— **no key is stored in this repo** (see `.gitignore`).

Exit codes (CI): `0` = not AI-likely · `1` = AI-likely.

## Verdict thresholds (from the gold set, in-sample)

| language | human-likely | ambiguous | AI-likely |
|---|---|---|---|
| Cantonese | < 0.32 | 0.32 – 0.43 | > 0.43 |
| English | < 0.49 | 0.49 – 0.55 | > 0.55 |

## Verification (summary — full report in `eval/VERIFICATION.md`)

72 attributed gold cases (real LIHKG/HN = human; deepseek-v4-flash output = AI).
Five decision-prompt variants benchmarked by AUROC → **many-shot won**
(Canto 0.999 / EN 0.995). Shipped result: **0 FP, 0 FN**; Cantonese 11/12 AI
caught, English 7/8.

**Caveat:** thresholds are in-sample and the gold set is comparatively easy
(short human + uniform ragebait AI — see `eval/README.md`). The prompt ranking
is robust; absolute accuracy needs a harder, held-out set before any external
claim.
