# ai-slop-detector

A **standalone** rubric-based human/AI tone scorer. Given any text (Cantonese
or English, works at ANY length incl. short ragebait posts), it returns a
verdict (`human-likely` / `ambiguous` / `AI-likely`), an AI probability, and a
confidence, plus a per-trait breakdown. Powered by **Jev via OpenRouter**
(~$0.000015/text). Designed to be run directly, piped, or called from scripts /
CI. **Deliberately NOT bundled into the sikaoge-* skills** — call it on demand.

> v1.1: the `machine_written` signal is **concrete-anchored** (real-human vs
> AI-draft exemplars). Laya was removed — it over-fired on short Cantonese
> (17/28 human false-positives in the gold test).

## When to use

- Check whether a draft (a post, a product blurb, an essay, a PR description)
  *reads* AI-sounding before you publish — especially Cantonese ragebait at
  short length, where GPTZero-type perplexity detectors are pure noise.
- Review someone else's text for AI tells, or a batch of submissions.
- As an editor's second opinion: it names specific traits (triple-questions,
  "真相係" reveals, no concrete detail…) so you know *what* to fix.

## Honesty first (read this before trusting any score)

- This is a **pattern/rubric scorer, NOT a ground-truth detector**. "AI-likely"
  means *reads machine-written*, not *provably generated by a model*.
- 3-band verdict is the honest contract: the flanking bands (human / AI) were
  calibrated on a 72-case gold set to carry **0 false-positives and 0
  false-negatives**; anything borderline returns `ambiguous` rather than
  guessing. **Trust `ambiguous` as "read it yourself", not as a classification.**
- Confidence here = **agreement** between the trait rubric and the direct
  model reading. Agreement ≠ accuracy; it is signal consensus.
- Use for a **read-only/review** action. Do not use this to accuse people,
  deny credit, or fire anyone. No tool can prove authorship.

## Usage

```bash
SCRIPT=~/ai-slop-detector/detect.py
#   (the installed Hermes skill at ~/.hermes/skills/creative/ai-slop-detector/
#    is a symlink to this same file — repo is the single source of truth)

# inline text (default: Jev auto-detects language zh/en)
python3 "$SCRIPT" --text "你的廣東話帖 ..."

# English text (forced)
python3 "$SCRIPT" --lang en --text "An obvious AI sentence..."

# from a file, or piped
python3 "$SCRIPT" --file post.txt
cat post.txt | python3 "$SCRIPT"

# machine-readable JSON
python3 "$SCRIPT" --text "..." --json
```

Backend: `--backend auto` (default) == `--backend jev`. Laya and `ensemble`
were removed in v1.1 (single model now).

Exit codes (CI-friendly): `0` = not AI-likely; `1` = AI-likely.

## The rubric (7 AI tells, weighted)

| trait | what it flags | weight |
|---|---|---|
| `reveal_trope` | "真相係／問題係／本質係——" big-reveal constructions | 1.4 |
| `triple_question` | 3+ rhetorical questions in a row | 1.0 |
| `perfect_antithesis` | too-perfect "唔係X，係Y" parallels | 1.0 |
| `abstraction` | generic, no numbers/names/places/times | 1.4 |
| `over_balanced` | lists both sides, no edge/stance | 1.0 |
| `even_rhythm` | too-uniform sentence rhythm | 0.8 |
| `hashtag_stack` | 5+ hashtags (skipped if none) | 0.6 |

Each is asked as a Noul (0–1 probability the trait is present). The verdict runs
on the **direct `machine_written` question** (many-shot) alone; the 7 traits are
reported as an editing breakdown and are not weighted into the verdict.

Thresholds (from real tests, per-language):
- Cantonese: `<0.32` human-likely, `0.32–0.43` ambiguous, `>0.43` AI-likely
- English:   `<0.49` human-likely, `0.49–0.55` ambiguous, `>0.55` AI-likely

## Calibration (from real tests, 72-case gold set)

- **The decision prompt matters more than the trait list.** A benchmark of five
  scoring prompts (many-shot, anchored-scale, 1-exemplar, behavioural
  definition, human-framed) ranked by AUROC picked the **many-shot** version
  (3 real-human + 3 AI-draft exemplars): Canto AUROC 0.999 / EN 0.995. Asking
  "how AI" beat asking "how human" (which collapsed Canto to near-random).
- Shipped result (Jev, both languages): **0 human falsely accused, 0 AI missed**
  on the gold set (zh 11/12 AI caught, en 7/8); marginal cases abstain.
- Caveat: thresholds were derived on the same set they were measured on
  (in-sample), on an easy gold set. Treat absolute numbers as optimistic; the
  *relative* prompt ranking is the reliable finding.

## Pitfalls

- Don't read a single-number score as truth — this is signal, not proof.
- Don't use it to accuse/manage-out a person (see Honesty first).
- `urllib.request` fails against the OpenRouter decisions endpoint on this host
  (401/403) — the script deliberately uses `http.client`. Keep that.
- Very short input (a sentence or two) → expect `ambiguous` / low confidence
  more often; that's correct, don't tune thresholds up to force calls.
